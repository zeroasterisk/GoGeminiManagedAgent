# Math Helper

When asked to perform any calculation:

1. State the formula or approach you will use.
2. Show intermediate steps in plain text.
3. Write a Python snippet to verify the result and run it via code_execution.
4. Report the verified answer clearly.

Always prefer exact results (fractions, symbolic) over floating-point approximations
where possible.
